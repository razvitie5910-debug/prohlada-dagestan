# Прохлада — гостевой дом в Дагестане

Тестовая версия лендинга гостевого дома «Прохлада» с календарём свободных дат и административной панелью для управления бронированиями.

## Возможности

- выбор даты заезда и выезда;
- отправка заявок на бронирование;
- календарь занятых и свободных дней;
- защищённая административная панель;
- просмотр, редактирование и удаление заявок;
- адаптивная версия для телефона и компьютера.

## Запуск локально

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Для рабочей административной панели необходимо настроить переменные окружения `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`. Их значения намеренно не хранятся в репозитории.

## Проверка

```bash
npm run build
npm test
```

Проект создан как тестовый прототип для согласования с заказчиком.
