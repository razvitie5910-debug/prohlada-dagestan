# Прохлада — гостевой дом в Дагестане

Информационный сайт-витрина гостевого дома «Прохлада». Посетитель может посмотреть территорию, условия и цены, позвонить хозяину, открыть WhatsApp, Instagram или маршрут на карте.

На сайте нет формы бронирования, календаря и сбора персональных данных посетителей.

## Управление ценами

Страница владельца находится по адресу `/admin/`. В ней можно изменить:

- цену отдыха без ночлега;
- количество гостей, включённых в эту цену;
- доплату за следующего гостя;
- те же параметры для отдыха с ночлегом.

После сохранения цены сразу обновляются на публичной странице. Значения хранятся в Netlify Blobs.

Пароль задаётся только в настройках Netlify через секретную переменную окружения `ADMIN_PASSWORD`. Пароль намеренно не хранится в публичном GitHub-репозитории.

## Публикация на Netlify

Настройки находятся в `netlify.toml`:

- команда сборки: `npm run build:netlify`;
- каталог публикации: `netlify-dist`;
- серверная функция цен: `netlify/functions/pricing.mjs`.

Перед первой публикацией необходимо добавить в Netlify переменную `ADMIN_PASSWORD` со значением, известным владельцу.

## Локальная сборка

Требуется Node.js 22 или новее.

```bash
npm install
npm run build:netlify
```
